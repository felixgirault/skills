The commit subject:

- Uses the `-ing` form, because the software keeps showing the line at runtime (e.g. "Showing an empty-state line when no source is configured"). A past-tense subject like "Showed…" fails.
- Is at most 72 characters, capitalised, with no prefix (`feat:`) and no final period.

A body, if present, is separated by a blank line and does not repeat the subject.
